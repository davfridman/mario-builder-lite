# Level Builder Lite

Build a platformer level in the browser, beat it, then share it as a link.
The whole level is encoded in the URL, so there is no backend.

Live: https://davfridman.github.io/mario-builder-lite/

- Edit: paint tiles with the mouse (1-9, S, G, E pick tiles)
- Play: Tab, then arrows/WASD + Space
- Share: unlocks once you have cleared your own level

Built for AICODE Lab 1 with a coding agent. Plain HTML/CSS/JS, hosted on GitHub Pages.
